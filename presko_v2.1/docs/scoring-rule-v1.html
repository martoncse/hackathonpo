How Decision Rule v1 turns a forecast into a school plan

Each classroom building gets a heat score for tomorrow's morning and afternoon. The score sets a colour band, the bands decide which classrooms can be used in each half of the day, and the number of usable classrooms decides the school's plan. Left column: the rule. Right column: the same step worked through for Pandac Elementary School on the demo closure day.

1

Forecast → heat index per half-day

Hourly temperature and humidity for 06:00–17:00 are converted to a heat index (the "feels-like" temperature PAGASA uses). The hours are then averaged into two class windows.

Morning windowaverage of 06:00–10:59
Afternoon windowaverage of 12:00–16:59

Hottest single hour: about 45°C at 14:00. The average hides it; see the caveats.

2

Heat index → forecast points

Each window earns points from its average heat index. The division coordinator can change these values, and any change creates a new rule version that must be approved again.

The same forecast points apply to every building in the school (one forecast covers the city).

3

Building → building points

Fixed for each building, so they only change when the records change. Features that trap heat add points and features that cool remove them. Two come from the National School Building Inventory (NSBI); the rest come from a five-question heat checklist the principal answers once.

Usable classrooms → school plan

A "section" is one class of pupils (for example Grade 3-A). Each section needs one classroom for one time slot.

7

Check, then the principal decides

An independent checker re-reads the plan and confirms that no section is left out, no room is double-booked and no class is in a room unsafe for its time slot. The principal then confirms or picks a different plan with a reason, as DepEd Order No. 37, s. 2022 requires.

Worked example

0 conflicts. Pandac's principal receives the SMS at 16:00 and confirms or overrides before the 17:00 cut-off.

Saying it in 30 seconds

  1. We take tomorrow's hourly forecast and work out how hot the morning and the afternoon will feel.
  2. Every classroom building has a heat score from how it's built: a tin roof with no ceiling or a west-facing wall makes it hotter, while ceilings, shade and cross-ventilation make it cooler.
  3. Forecast plus building gives each building a colour for each half-day: green, amber or red.
  4. Classes go only where it's safe: amber is fine in the cooler half of the day, the hotter half needs green, and red is never used.
  5. If every class fits safely all day, the school stays open. If not, it runs the half-day that fits the most classes, and only the classes that still don't fit learn from home.

What to be ready for in Q&A

  • The points are judgement, not measurement. No indoor temperature data backs them yet. A few classroom thermometers in one pilot division would let us calibrate them.
  • Averages hide peaks. The afternoon averages 44.6°C but reaches about 45°C at 14:00. A peak-based rule would be stricter.
  • One forecast for the whole city. Every school gets the same forecast points. Only the buildings differ.
  • Whole-building features. "Upper floor" adds +1 to every room in the building, including ground-floor rooms.
  • Thresholds have hard edges. 41.9°C scores 0 and 42.0°C scores +1, so a 0.1°C change in the forecast can flip a school's plan.
  • Split shifts halve learning time. Two 2.5-hour shifts keep pupils in school but give each section well under half a normal day.
