Day beforePAGASA → coordinator

The DRRM coordinator types PAGASA's latest heat-index forecast for tomorrow. The 5 p.m. advisory is the official trigger, so Presko is re-run when it lands.

16:00Presko

On the latest forecast: a 4H level for every school, a plan, rooms to check, a draft request, a draft message.

16:30School head

Confirms or changes the level and records the decision, with a reason if it differs.

16:45SDO

Approves or returns decisions. Approval is required when a decision is less protective than the rule.

by 17:00School head

Official message to parents: school page, class group chats, radio. Log goes to the SDO as CSV.

08:00School, next day

Indoor reading per building. Hotter buildings are emptied; if all read hotter, the school steps up a level.

Practice reported in Mandaue: heads set the next day's level between 16:00 and 17:00. Iloilo City's EO 24 keys on PAGASA's 5 p.m. advisory, so a changed forecast marks earlier decisions "re-confirm".

Engine · intermediate variables
1

Note → features

Claude reads each note into 9 true/false features with quoted evidence; a keyword fallback runs without AI. Never a temperature.

2

Features → building flag

Points summed per building, then cooler / typical / hot. Each room inherits its building's flag.

points = Σ FEATURES[f] · flag = BAND_RULE(points)
3

Forecast → 4H level

From PAGASA's forecast, raised to Hinga if there is no water.

HAYO<27°CHINAY27–32HINGA33–41HINTO≥42
4

Readings → building and school level

Each building with an 8:00 reading takes the worse of forecast and reading. The school takes its coolest building. Buildings hotter than that are emptied.

level_b = worse(forecast, reading_b) recommended = min over buildings(level_b)
5

Decision → effective level

The head's recorded level replaces the recommendation for that forecast. A forecast change makes it stale.

effective = decided ?? recommended
6

Level + rooms + timetable → plan

Hayo: usual timetable, all open rooms. Hinay: non-hot rooms, 06–10 then 14–18. Hinga: home-based, plus a draft F2F request if cooler rooms qualify. Hinto: nothing.

section → (room, slot) | home | none
7

Independent check

Re-derives the level from the inputs and tests every assignment: nobody 10:00–14:00 on Hinay, no hot rooms on Hinay, no F2F on Hinga without approval, nothing on Hinto, no emptied building used, no double-booking, every section once.

8

Decision status

none → recorded → (if less protective) awaiting SDO → official, or returned. Only official messages are marked ready to send.

Replay only: hourly T, RH → NWS heat index → max 11:00–16:00 → +3.7°C
